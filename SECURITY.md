# Security Policy

Hermes Achievements is a static, public-safe showcase. It intentionally contains no live Hermes connection, authentication, user input, or private runtime history.

If you find a credential, private path, session detail, or other sensitive value, do not paste it into a public issue. Report only the affected file and value class so the maintainer can remove it and review Git history.

Before publication, maintainers should verify the current tree and Git history for tokens, private keys, local paths, usernames, raw logs, and generated evidence files.
